# SQL Practice

My SQL learning log, built while working through [SQLBolt](https://sqlbolt.com/) and practicing in MySQL Workbench.

## What's here

| File | Covers |
|---|---|
| `select.sql` | Basic `SELECT` statements — retrieving and reading data from tables |
| `queries_with_constraints.sql` | Filtering rows with `WHERE`, comparison operators, and logical constraints |
| `filtering_and_sorting.sql` | Combining filtering with `ORDER BY` and sorting results |

Each file has comments explaining what the query does and what I learned from that lesson — this is a practice log, not a finished project.


## Tools used

- [SQLBolt](https://sqlbolt.com/) for structured lessons
- MySQL Workbench for hands-on practice

In progress — working through SQLBolt lesson by lesson.
